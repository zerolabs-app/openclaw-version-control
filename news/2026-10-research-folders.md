# New: research folders and job notes

## Research folders
Add one line to a prompt's criteria to keep files between runs - saved headlines, charts, scripts, history:

- Research Folder: my-topic

Any prompt that names the same folder shares it, so one prompt can collect and another can dig deeper. Each result gives the File Explorer address of what it saved, and Tools → Open Research Folders opens them all.

## Job notes (Full)
Every scheduled job keeps its own notes: your standing instructions plus a short history it writes after each run, so each run knows what earlier runs found. Open them in Tools → Scheduled Jobs → Notes.
